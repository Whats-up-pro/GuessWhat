# Khi nào tớ qua được nè? 🐾

Trang web hẹn lịch tối giản, ấm áp và siêu dễ thương gửi bạn bè.

🔗 **Link Trực Tiếp:** [https://whats-up-pro.github.io/GuessWhat/](https://whats-up-pro.github.io/GuessWhat/)

### ✨ Đặc điểm thiết kế:
* **Kawaii & Minimal**: Phong cách tối giản, tập trung hoàn toàn vào việc chốt lịch nhanh trong 3 giây.
* **Mascot Mèo Con**: Bé mèo đáng yêu bay lơ lửng, đổi trạng thái ăn mừng khi người bạn chốt lịch thành công.
* **Bảng màu Pastel**: Kem (cream), hồng phấn (blush pink), tím lavender và cam đào (soft peach).
* **Trải nghiệm Mobile-first**: Nút bấm to dạng bubble (≥ 64px), hiệu ứng nhún (squish animation) cực cuốn khi chạm, âm thanh pop bong bóng mềm mại.
