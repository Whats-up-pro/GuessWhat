### ✨ Tính Năng Nổi Bật:
1. **🔢 Đoán Số Bí Ẩn**: Thử thách đoán số có điều chỉnh độ khó (1-50, 1-100, 1-500) và số lượt chơi giới hạn.
2. **🧩 Giải Mã Emoji**: Đuổi hình bắt chữ thú vị qua các biểu tượng emoji.
3. **💡 Sự Thật Thú Vị (Trivia)**: Khám phá những kiến thức kỳ thú qua các câu hỏi "Guess What?".
4. **🎉 Hiệu Ứng & Trải Nghiệm**: Tích hợp âm thanh sinh động (Web Audio API không cần tải file ngoài), pháo hoa confetti, giao diện Glassmorphism Neon hiện đại và tương thích di động hoàn hảo.
